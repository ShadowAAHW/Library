## Цель работы

## Постановка задачи

Разработать консольное приложение для автоматизации учёта книжного фонда библиотеки. Программа должна обеспечивать добавление, редактирование, удаление записей о книгах, поиск и фильтрацию каталога, сортировку, расчёт аналитических показателей, а также сохранение и загрузку данных в текстовом формате `.txt`.

## Инструкция по установке и запуску

### Требования

- Компилятор с поддержкой C++17 (GCC ≥ 7, MSVC ≥ 2017, Clang ≥ 5)
- CMake ≥ 3.16 (опционально, если собирать через CMake)

### Вариант 1: Сборка через CMake (рекомендуется)

```bash
git clone https://github.com/ShadowAAHW/library
cd library
mkdir build && cd build
cmake ..
cmake --build .
```

**Запуск:**
- Windows: `LibraryApp.exe` (в папке `build`)
- Linux / macOS: `./LibraryApp`

### Вариант 2: Сборка через g++ вручную

```bash
git clone https://github.com/ShadowAAHW/library
cd library
g++ -std=c++17 src/*.cpp -o LibraryApp
./LibraryApp
```

### Вариант 3: Visual Studio

1. Создать пустой C++ проект.
2. Добавить все файлы из `src/`.
3. В свойствах проекта установить **C++ Language Standard = C++17**.
4. В свойствах компилятора добавить флаг `/utf-8` (для корректной работы с кириллицей в исходниках).
5. Собрать и запустить.

> ℹ️ При первом запуске программа автоматически создаст папку `data/` и пустой файл `catalog.txt`, если их нет.

## ✨ Реализованный функционал

### 1. Управление данными (CRUD)

- ✅ Добавление книги с автогенерацией уникального ID
- ✅ Редактирование существующей записи (с возможностью оставить поля без изменений)
- ✅ Удаление по ID или по названию
- ✅ Валидация: год издания > 0, количество экземпляров ≥ 0, цена ≥ 0, непустые строки, уникальный ID

### 2. Поиск и фильтрация

- ✅ По названию (частичное совпадение, регистронезависимо, работает с кириллицей)
- ✅ По автору или жанру (частичное совпадение, регистронезависимо)
- ✅ По диапазону года издания (от–до)
- ✅ По диапазону цен (от–до)

### 3. Сортировка

- ✅ По году издания (возрастание / убывание)
- ✅ По количеству доступных экземпляров (возрастание / убывание)
- ✅ По алфавиту названия или автора (А→Я)

### 4. Аналитика

- ✅ Общая стоимость всего книжного фонда
- ✅ Список книг, требующих пополнения (остаток ≤ 2 шт.)
- ✅ Топ-3 самых дорогих позиций в каталоге

### 5. Работа с файлами

- ✅ Автоматическая загрузка `data/catalog.txt` при старте
- ✅ Ручное сохранение изменений по команде пользователя
- ✅ Формат строки: `id,title,author,genre,year,copies,price`
- ✅ Защита от потери данных: при выходе программа спросит, сохранить ли несохранённые изменения

### 6. Интерфейс

- ✅ Консольное текстовое меню с циклической навигацией
- ✅ Корректное отображение и ввод кириллицы в Windows (через `SetConsoleOutputCP(65001)` и WinAPI `ReadConsoleW`)
- ✅ Обработка некорректного пользовательского ввода (буквы вместо чисел, пустые поля) без аварийного завершения
